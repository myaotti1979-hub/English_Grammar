# Syntax — ビジネス英文法トレーニング (PWA)

TOEIC 800 → 900 と、実務の会話・ライティングのための英文法アプリ。
23ユニット / 240問。オフライン動作。学習データは端末内に保存されます。

## ファイル構成

```
.
├── index.html      アプリ本体（HTML/CSS/JS と教材データをすべて内包）
├── manifest.json   ホーム画面追加・アプリ名・アイコン・ショートカット
├── sw.js           Service Worker（オフラインキャッシュ）
├── .nojekyll       GitHub Pages の Jekyll 処理を無効化
└── icons/
    ├── icon-192.png
    ├── icon-512.png
    ├── icon-maskable-512.png   Android の丸型アイコン用（余白広め）
    ├── apple-touch-icon.png    iOS ホーム画面用 180px
    └── favicon-32.png
```

すべて相対パス (`./`) 参照なので、`https://ユーザー名.github.io/リポジトリ名/`
のようなサブディレクトリ配信でもそのまま動きます。

## GitHub Pages への公開手順

1. GitHub で新しいリポジトリを作成する（例: `syntax-grammar`）
2. このフォルダの中身を **リポジトリ直下** にアップロードする
   （`index.html` がリポジトリのルートに来るように。`pwa/index.html` のような入れ子にしない）
3. すべてのファイルが**同じ階層（ルート直下）**に並んでいることを確認する
4. リポジトリの **Settings → Pages** を開く
5. **Source** を `Deploy from a branch`、Branch を `main` / `/ (root)` にして Save
6. 1〜2分待つと `https://ユーザー名.github.io/リポジトリ名/` で公開される

コマンドで行う場合:

```bash
git init
git add .
git commit -m "Syntax grammar app"
git branch -M main
git remote add origin https://github.com/ユーザー名/リポジトリ名.git
git push -u origin main
```

## スマホへのインストール

- **Android (Chrome)**: サイトを開く → メニュー →「アプリをインストール」
- **iOS (Safari)**: サイトを開く → 共有ボタン →「ホーム画面に追加」

インストール後は起動時にアドレスバーが消え、機内モードでも動作します。
Android では長押しで「瞬間英作文」「模試」「復習」のショートカットが出ます。

## アプリを更新したとき

`index.html` を書き換えたら、**必ず `sw.js` の `VERSION` を上げてください。**

```js
const VERSION = 'v1.0.2';   // ← ここを変える
```

これを忘れると、Service Worker が古いキャッシュを返し続けて更新が反映されません。
バージョンを上げてアップロードすると、次にアプリを開いたときに
「新しいバージョンがあります」と表示され、開き直すと反映されます。

## AIで問題を追加する（Gemini）

「作る」タブから、Google の Gemini に新しい演習問題を作らせて追加できます。

1. https://aistudio.google.com/apikey で無料のAPIキーを発行する
2. アプリの「作る」タブ →「APIキーの設定」に貼り付けて保存
3. 単元・問題数・難易度・出題形式を選んで「問題を生成する」
4. 内容を確認して「アプリに追加する」

追加した問題は、その単元の演習・ミックス演習・模試にそのまま出題され、
間違えれば復習リストにも入ります。単元ごとにまとめて削除もできます。

- モデルは `gemini-3.7-flash` 固定です
- 「思考の深さ」を high / medium / low から選べます。作問は推論が効くので high 推奨
- APIキーはこの端末の localStorage にのみ保存され、Google 以外には送信されません
- 生成にはネット接続が必要です（アプリ本体はオフラインで動きます）
- AIの生成物なので、まれに不自然な英文が混じります。追加前に必ず確認してください

## 音声読み上げ

解答の英文や瞬間英作文の問題文を音声で再生できます（端末の音声合成を使用、追加ファイルなし）。
記録タブの「読み上げの設定」で、自動再生の有無と英語の速さ（ゆっくり／標準／速め）を選べます。
自動再生を有効にすると、瞬間英作文は日本語が読まれ、答え合わせで英文が流れるので、
画面を見ずに通勤中などに回せます。

## 間隔反復（忘却曲線に沿った復習）

一度解いた問題は、忘れかけたころに自動で出し直されます。

- 正解するたびに **1日 → 3日 → 1週間 → 2週間 → 1か月 → 2か月** と間隔が伸びます
- 間違えると翌日に戻ります
- 5回連続で正解した問題は「定着」として扱われます

復習タブに「今日の復習」が出るので、新しい単元より先にここを空にするのが最も効率的です。

## 間違いの原因を自動で判定

不正解のとき、**選んだ誤答と正解を比較して原因を自動で特定します**。
自己申告ではなく、選択肢の差分から機械的に判定するので確実です。

例：`discussing` を選んで正解が `to discuss` なら「動詞の形」、
`because` を選んで正解が `due to` なら「つなぐ語の選択」、
`have` を選んで正解が `has` なら「主語と動詞の一致」。

判定できる原因は13種類（時制・態／能動と受動／品詞／動詞の形／主語と動詞の一致／
つなぐ語／前置詞／関係詞／比較／冠詞・可算不可算／語彙／文脈／語順）。
収録済みの全問題で検証したところ、誤答パターンの **96%** を自動分類できています。

解答が極端に速い場合は、文法上の原因はそのまま記録したうえで「急いで選んでいます」の注意を併記します。
判定が違うと感じたら「違う」から手動で直せます。
選択肢のない瞬間英作文・ライティングだけは、任意で自己申告できます。

記録タブに集計が出て、最も多い原因に応じた助言が表示されます。

## AIによる傾向診断

分類の集計だけでは見えない「間違い方の癖」を、Gemini が直近60件の誤答から分析します。
記録タブの「AIに傾向を診断させる」から実行できます（誤答が10件以上たまると使用可能）。

「前置詞の誤りが多い」といった件数のなぞりではなく、
「空所の後ろが名詞か文かを確認せずに意味だけで選んでいる」のような
行動レベルの原因まで踏み込むよう指示しています。今日から実行できる行動が3つまで提示されます。

## Part 6（長文穴埋め）

メール・社内通知・応募書類・顧客案内の4文書。各文書に空所4つ（うち1つは文挿入問題）で、
本番と同じ構成です。解いた空所には正解が埋まっていくので、文書全体の流れを追いながら進められます。

## 振り返りメモ

記録タブから開きます。1日1件、その日つまずいたことを書き残せます。
その日の誤答傾向がヒントとして表示されるので、それを見ながら書けます。

## AI 添削（ライティング課題）

ライティング課題で自分の答案を書いたあと、「AIに添削してもらう」を押すと
Gemini が採点・添削します。100点満点の評価、できている点、直すとよい点（最大4件、
訂正前後と理由）、自然な形に直した英文、次に気をつけることが返ります。
模範解答と違っていても、英語として自然なら減点しない方針で指示しています。
APIキーの設定が必要です。

## 出題レベルの基準

AI生成問題の難易度は、次の公開基準にもとづいて定義しています。
アプリ内の「作る」タブ →「基準について」でも確認できます。

- **CEFR との対応** … ETS の標準設定研究（Tannenbaum & Wylie, 2006
  "Mapping the TOEIC Tests on the CEFR"）。総合 550〜784=B1 / 785〜944=B2 / 945〜990=C1。
  Reading セクションの最低スコアは B1=275 / B2=385 / C1=455
- **語彙の範囲** … NGSL（高頻度2,801語）＋ TOEIC Service List（1,200語）で
  TOEIC の語彙の 98.5〜99% をカバー（Browne & Culligan）。この範囲を TOEIC 圏として扱う
- **Part 5 の仕様** … 30問・各文に空所1つ・4択。推奨ペースは30問で約12分
- **文法段階** … CEFR の段階に従い、B2＝完了形・受動各形・分詞構文・仮定法・whose、
  C1＝倒置・強調構文・混合条件・複合前置詞

生成された問題は、語数・節の数・語彙層・構文・誤答の紛らわしさの5点から
推定レベルを算出し、指定と一致しない問題には印がつきます。
「一致した問題だけ追加」も選べます。

なお本来 TOEIC の難易度は項目応答理論による統計値で決まるため、
文面からの判定はあくまで近似です。最も信頼できるのは実際の正答率で、
AI生成問題を5問以上解くと、記録タブに「出題レベルの妥当性」が表示されます。
正答率が目安の帯から外れたら、生成時のレベルを上下させてください。

## 学習の分析（記録タブ）

解いた問題は、単元・分野・出題形式ごとに集計され、記録タブで可視化されます。

- **次にやること** … 現在の状態から最優先の行動を1つ提案。そのまま該当画面へ移動できます
- **分野別の実力** … 時制・接続・関係詞・品詞語法・会話作文の5軸レーダー
- **学習の記録** … 直近13週の学習量ヒートマップ
- **正答率の推移** … 直近2週間の日別正答率
- **出題形式ごとの成績** … 四択と瞬間英作文の差から「知識」と「速さ」のどちらが課題かを判定
- **単元別の正答率** … 23単元を色分け表示。タップで解説へ
- **重点的に直すところ** … 正答率の低い単元を上位3つ、分野別の助言つきで表示

## 機種変更・バックアップ

「記録」タブの下部にある「データの書き出し・読み込み」から、学習データを
JSONファイルとして保存・復元できます。

**書き出す（旧端末）**
1. 記録タブ →「データの書き出し・読み込み」
2. 「ファイルに書き出す」を押すと `syntax-backup-YYYYMMDD-HHMM.json` が保存される
3. そのファイルをメール・クラウド・AirDrop などで新しい端末に移す

**読み込む（新端末）**
1. 同じ画面で「ファイルを選ぶ」
2. 内容（単元数・解いた問題数・復習待ち・AIで追加した問題）を確認
3. 復元のしかたを選んで「復元する」
   - **すべて置き換える** … 機種変更後の新端末向け
   - **いまのデータに足す** … 統合。成績は良いほうを採用し、AIで追加した問題は重複を避けて足す

ファイルのやりとりが面倒な場合は、クリップボード経由でも移せます。

バックアップに含まれるもの: 単元ごとの成績、通算の正答率、連続学習日数、
模試の最高スコア、復習リスト、AIで追加した問題。
APIキーは既定では含まれません（含めて書き出すこともできます）。

## 学習データについて

- 進捗・正答率・復習リスト・AIで追加した問題・APIキーはブラウザの localStorage に保存されます
- 端末とブラウザごとに独立しています（機種変更では引き継がれません）
- 「記録」タブの一番下から全消去できます
- サーバーには何も送信されません

## 日本語フォント

日本語は Noto Sans JP を Google Fonts から読み込みます。
オフライン時や読み込み失敗時は、端末標準の日本語ゴシック
(Hiragino Kaku Gothic ProN / Yu Gothic / Meiryo) にフォールバックします。
中華フォントが混ざらないよう、フォールバック指定と `lang="ja"` を明示しています。

完全にオフラインでも Noto Sans JP を使いたい場合は、フォントファイルを
`./` に置いて `index.html` の Google Fonts の `<link>` を
`@font-face` の自前定義に差し替え、`sw.js` の `CORE_ASSETS` にパスを追加してください。
